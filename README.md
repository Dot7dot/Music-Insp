# Music Insp

音乐创作者的「灵感碎片收集簿」，以 GitHub Pages 发布的纯前端网页。

👉 **线上使用：https://dot7dot.github.io/Music-Insp/**

## 功能

- **歌曲资料夹**：每首歌建立一个资料夹，可以重新命名、删除。
- **灵感碎片**：在资料夹里
  - 直接用麦克风**录音**（录完可马上命名，例如「人声录音 A」「吉他录音 A」）
  - **上传**任何档案：录音、图片、影片、PDF……也支援拖曳
  - 每个碎片都可以**命名**、试听 / 预览、单独下载、删除
- **备注**：每个资料夹都有一块自动储存的备注区，可写歌词、和弦、编曲想法等。
- **汇出 ZIP**：一键把整个资料夹打包成 `歌曲名称.zip`，内含所有碎片（以你取的名字命名）与 `备注.txt`。
  可勾选「录音转 WAV」，把浏览器录下的 webm / m4a 转成 WAV，方便直接拖进 DAW。

## 资料储存

所有资料都存在**你自己的浏览器**（IndexedDB）里，不会上传到任何伺服器。

- 不同浏览器 / 装置之间资料不会同步。
- 清除浏览器网站资料会把资料一起删除，请定期「汇出 ZIP」备份。
- 网页会向浏览器申请「永久储存」，降低被自动清理的机会。

## 本机开发

不需要建置，用任何静态伺服器开启即可（录音需要 `https` 或 `localhost`）：

```bash
python3 -m http.server 8000
# 打开 http://localhost:8000
```

## 部署

推送到 `main` 后，`.github/workflows/pages.yml` 会把网页档案发布到 `gh-pages` 分支，GitHub Pages 再从该分支自动更新网站。

第三方元件：[JSZip](https://stuk.github.io/jszip/) 3.10.1（MIT，放在 `vendor/`）。
