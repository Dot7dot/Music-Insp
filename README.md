# Music Insp

音樂創作者的「靈感碎片收集簿」，以 GitHub Pages 發布的純前端網頁。

👉 **線上使用：https://dot7dot.github.io/Music-Insp/**

## 功能

- **歌曲資料夾**：每首歌建立一個資料夾，可以重新命名、刪除。
- **靈感碎片**：在資料夾裡
  - 直接用麥克風**錄音**（錄完可馬上命名，例如「人聲錄音 A」「吉他錄音 A」）
  - **寫文字**：歌詞、旋律、和弦、編曲想法，每一則都是獨立的一小格。
    收合時只顯示前三行，點一下就能展開看完整內容並直接編輯（自動儲存，按 Esc 收合）
  - **上傳**任何檔案：錄音、圖片、影片、PDF……也支援拖曳
  - 每個碎片都可以**命名**、試聽 / 預覽、單獨下載、刪除
- **匯出 ZIP**：一鍵把整個資料夾打包成 `歌曲名稱.zip`，內含所有碎片（以你取的名字命名，文字碎片會變成 `.txt`）。
  可勾選「錄音轉 WAV」，把瀏覽器錄下的 webm / m4a 轉成 WAV，方便直接拖進 DAW。

> 舊版資料夾的「備註」會在打開資料夾時自動搬進靈感碎片，變成一則名為「備註」的文字碎片。

## 資料儲存

所有資料都存在**你自己的瀏覽器**（IndexedDB）裡，不會上傳到任何伺服器。

- 不同瀏覽器 / 裝置之間資料不會同步。
- 清除瀏覽器網站資料會把資料一起刪除，請定期「匯出 ZIP」備份。
- 網頁會向瀏覽器申請「永久儲存」，降低被自動清理的機會。

## 本機開發

不需要建置，用任何靜態伺服器開啟即可（錄音需要 `https` 或 `localhost`）：

```bash
python3 -m http.server 8000
# 開啟 http://localhost:8000
```

## 部署

推送到 `main` 後，`.github/workflows/pages.yml` 會把網頁檔案發布到 `gh-pages` 分支，GitHub Pages 再從該分支自動更新網站。

第三方元件：[JSZip](https://stuk.github.io/jszip/) 3.10.1（MIT，放在 `vendor/`）。
